# EmojiChatPlugin 🌟

EmojiChatPlugin is a Spigot/Paper plugin that lets players use emojis in chat using shortcodes like `:star:`.

## Features
- Supports Minecraft 1.20.1 – 1.26.1
- Add custom images in the `emojis` folder
- Commands:
  - `/emojis help` – Show help
  - `/emojis list` – Show emoji list

## Installation
1. Place it in your server `plugins` folder.
2. Restart your server

## Usage
Type `:emoji_name:` in chat to display the emoji. Example: `:star:` → ⭐
